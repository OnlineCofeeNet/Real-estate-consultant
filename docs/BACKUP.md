# پشتیبان‌گیری خودکار سامانه

سامانه اکنون یک لایه پشتیبان‌گیری سمت سرور دارد و برای اجرای نصبی روی ویندوز، اجرای سرویس روی سرور و اجرای کلاینت‌های وب/اندروید قابل استفاده است.

## رفتار پیش‌فرض

- پشتیبان‌گیری خودکار فعال است.
- فاصله پیش‌فرض: هر ۳۰ دقیقه.
- قبل از خاموش شدن کنترل‌شده برنامه، یک پشتیبان خروجی ساخته می‌شود.
- در اولین اجرای بدون پشتیبان، یک پشتیبان startup ساخته می‌شود.
- حداکثر ۳۰ نسخه نگهداری می‌شود و نسخه‌های قدیمی حذف می‌شوند.
- فایل‌ها در پوشه `backups/` با فرمت فشرده `json.gz` ذخیره می‌شوند و در Git commit نمی‌شوند.

## تنظیمات

تنظیمات در رکورد `settings` و در فیلد JSON با نام `backupSettings` قرار می‌گیرد:

```json
{
  "backupSettings": {
    "enabled": true,
    "intervalMinutes": 15,
    "backupOnExit": true,
    "retentionCount": 60
  }
}
```

مقادیر معتبر:

- `enabled`: روشن/خاموش کردن پشتیبان‌گیری.
- `intervalMinutes`: فاصله بین پشتیبان‌ها، حداقل ۱ دقیقه و حداکثر ۱۴۴۰ دقیقه.
- `backupOnExit`: ساخت پشتیبان هنگام خروج کنترل‌شده.
- `retentionCount`: تعداد نسخه‌های نگهداری‌شده، از ۱ تا ۳۶۵.

## محتوای پشتیبان

پشتیبان شامل داده‌های اصلی PostgreSQL است: کاربران، مشتریان، قراردادها، فاکتورها، پرداخت‌ها، پیام‌ها، گزارش ممیزی، تنظیمات، املاک، مناطق، تصاویر/رسانه‌های ثبت‌شده و درخواست‌ها/اشتراک‌های ملک. فایل‌های `bot-settings.json` و `bot-users.json` نیز در صورت وجود در بسته پشتیبان قرار می‌گیرند.

> توجه: پشتیبان فعلی «داده‌محور» است؛ فایل‌های حجیم رسانه‌ای که در S3 یا فضای فایل محلی نگهداری می‌شوند خود فایل باینری نیستند و URL/metadata آن‌ها در پشتیبان ثبت می‌شود. برای بازیابی کامل رسانه‌ها باید از خود فضای ذخیره‌سازی نیز backup جداگانه گرفته شود.

## معماری اجرا

`npm dev` و `npm start` از supervisor استفاده می‌کنند. supervisor فرآیند اصلی سرور را اجرا و کنترل می‌کند و زیرسیستم backup مستقل از رابط کاربری کار می‌کند. بنابراین بسته شدن تب مرورگر یا خروج کاربر باعث از دست رفتن داده‌های سرور نمی‌شود؛ زمان‌بندی روی سرور انجام می‌شود.

برای نصب ویندوز، توصیه می‌شود پوشه `backups/` روی دیسک دیگری یا یک مسیر شبکه‌ای نیز به‌صورت دوره‌ای کپی شود. برای سرور آنلاین، بهتر است علاوه بر این backup محلی، نسخه‌ای خارج از همان سرور (S3/Object Storage یا سرور پشتیبان) نیز نگهداری شود.
