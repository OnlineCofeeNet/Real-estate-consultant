# مدیریت کاربران

سامانه اکنون علاوه بر احراز هویت اولیه، مدیریت چرخه عمر کاربران را نیز در لایه local-first پشتیبانی می‌کند.

## نقش‌ها

- `admin`: مدیریت کامل سامانه و کاربران
- `manager`: قراردادها، مشتریان و امور مالی
- `agent`: قراردادها و مشتریان
- `accountant`: امور مالی و عملیات مرتبط

## قابلیت‌ها

- ایجاد کاربر جدید توسط مدیر
- تعیین نقش کاربر
- تغییر نقش کاربران غیرمدیر
- تغییر رمز عبور
- حذف کاربران غیرمدیر
- جلوگیری از حذف حساب فعال
- جلوگیری از ایجاد/حذف/تنزل حساب مدیر سیستم از رابط مدیریت کاربران
- ثبت عملیات مدیریتی در Audit Log محلی

> این ماژول همچنان به معماری IndexedDB متکی است. برای استقرار چندکاربره واقعی، کنترل‌های بالا باید در API سمت سرور و پایگاه داده مرکزی نیز اعمال شوند.
