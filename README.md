# مشاور املاک فراز | Real Estate Consultant

سیستم جامع مدیریت مشتریان، قراردادها، فاکتور و امور مالی ویژه مشاوران املاک.

یک وب‌اپلیکیشن مدرن با رابط کاربری کاملاً فارسی و راست‌چین (RTL)، پشتیبانی از تاریخ جلالی، چاپ حرفه‌ای قرارداد و فاکتور، و اتوماسیون پیامک و پیام‌رسان‌های ایرانی.

---

## ویژگی‌ها

### مدیریت مشتریان
- ثبت و مدیریت کامل اطلاعات مشتریان (نام، کد ملی، تلفن، تاریخ تولد و ...)
- پشتیبانی از چندین نقش برای هر مشتری (مالک، مستأجر، خریدار، فروشنده و ...)
- پیگیری بدهی، چک‌های وصول‌نشده و تاریخ پایان قرارداد
- شناسه پیام‌رسان‌ها (تلگرام، بله، روبیکا) و ارسال خودکار پیام

### قراردادها
- ثبت قراردادهای رهن، اجاره، خرید و فروش
- محاسبه خودکار کمیسیون، مالیات و مبلغ قابل پرداخت
- پشتیبانی از دو طرف قرارداد با سهم‌بندی
- ثبت روش پرداخت (نقد، چک، کارت‌خوان) و وضعیت POS
- قالب چاپ حرفه‌ای و خروجی PDF

### مالی و فاکتور
- صدور خودکار فاکتور برای هر طرف قرارداد
- ثبت پرداخت‌ها و پیگیری وضعیت
- گزارش‌های مالی و داشبورد خلاصه

### اتوماسیون و پیام‌رسان
- ارسال خودکار پیام مناسبت‌ها و یادآوری اجاره
- پشتیبانی از تلگرام، بله، روبیکا و SMS
- لاگ کامل ارسال پیام‌ها

### سایر امکانات
- احراز هویت امن با نقش‌های مختلف (Admin / Manager / Agent / Accountant)
- پشتیبانی کامل از تاریخ جلالی
- تم روشن/تاریک و تنظیمات ظاهری
- پشتیبان‌گیری و بازیابی خودکار
- رابط کاربری واکنش‌گرا و مناسب موبایل

## نصب و راه‌اندازی

### ۱. کلون کردن پروژه

```bash
git clone https://github.com/OnlineCofeeNet/Real-estate-consultant.git
cd Real-estate-consultant
```

### ۲. نصب وابستگی‌ها

```bash
npm install
```

### ۳. تنظیم متغیرهای محیطی

فایل `.env` را در ریشه پروژه بسازید (می‌توانید از `.env.example` کپی کنید):

```env
# دیتابیس PostgreSQL
SQL_HOST=localhost
SQL_PORT=5432
SQL_USER=postgres
SQL_PASSWORD=your_password
SQL_DATABASE=real_estate

# امنیت
AUTH_SECRET=یک_رشته_بلند_و_تصادفی_حداقل_۳۲_کاراکتر
NODE_ENV=development
```

> **توجه:** هرگز فایل `.env` را در گیت کامیت نکنید.

### ۴. اجرای پروژه در حالت توسعه

```bash
npm run dev
```

برنامه روی `http://localhost:3000` (یا پورت تعیین‌شده) اجرا می‌شود.

### ۵. بیلد و اجرای Production

```bash
npm run build
npm start
```

## نقش‌ها و دسترسی‌ها

| نقش | دسترسی |
|-----|--------|
| **admin** | دسترسی کامل به همه بخش‌ها و مدیریت کاربران |
| **manager** | مشتریان، قراردادها، مالی و تنظیمات عملیاتی |
| **agent** | مشتریان و قراردادها |
| **accountant** | بخش مالی و گزارش‌ها |

## وضعیت فعلی و برنامه آینده

پروژه در حال مهاجرت تدریجی از حالت **Local-first** به یک وب‌اپلیکیشن چندکاربره حرفه‌ای است.

**فازهای اصلی برنامه:**
1. تثبیت و پاکسازی کد
2. امنیت و احراز هویت سمت سرور
3. مهاجرت کامل داده به PostgreSQL
4. افزودن ماژول املاک (MLS) و درخواست مشتری
5. صف پیام حرفه‌ای و لاگ کامل
6. آماده‌سازی Production

جزئیات کامل در فایل [`docs/WEBAPP-UPGRADE.md`](docs/WEBAPP-UPGRADE.md) آمده است.

## مشارکت

اگر می‌خواهید در توسعه پروژه مشارکت کنید:

1. مخزن را Fork کنید
2. یک Branch جدید بسازید (`git checkout -b feature/amazing-feature`)
3. تغییرات را Commit کنید
4. به Branch خود Push کنید
5. یک Pull Request باز کنید

لطفاً قبل از ارسال PR، `npm run lint` و `npm run build` را اجرا کنید.
